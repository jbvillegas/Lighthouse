# Lighthouse

An offline-first survival and civil-protection knowledge base for Austria (with an EU reference layer). It ships as two things at once: **printed field manuals you can hold in your hand**, and **a local web app you can run without internet.**

In order to prevent this project from becoming a pile of PDFs that nobody can maintain please refer to `CONTRACT.md` for rules and instructions. 

## Why this exists

When something goes seriously wrong, such as **a blackout, a flood, a cyberattack that takes down infrastructure, or worse**, the internet is usually the first thing to go to. 
The information that would actually help you is spread across goverment sites, PDF brochures, Wikipedia, and forum posts, and none of it is organized and centralized for the moment you need it. 

Lighthouse collects that material, cites it honestly, and turns it into two outputs from one source: a print-ready PDF and a browsable local web app. Nothing here requires a network connection to use once you have it on disk. 

The initial scope is **Austria**. The architecture is built so that someone in Germany, Italy, or anywhere else can fork this and produce their own country pack without touching the Austrian content or the build scripts.
